# Code of conduct

## Our pledge

We pledge to make participation in Intra a harassment-free experience for
everyone, regardless of background, identity, experience level, or role.

## Expected behavior

- Be direct, specific, and respectful.
- Criticize code, evidence, and designs. Do not attack people.
- Assume good intent until conduct proves otherwise.
- Share credit and correct mistakes in public when the error was public.
- Protect private data, credentials, and security reports.

## Unacceptable behavior

- Harassment, threats, slurs, or sexualized conduct.
- Doxxing or publishing another person's private information.
- Repeated disruption after a maintainer asks for a change.
- Fraudulent security claims or knowingly false test evidence.
- Retaliation against a good-faith report.

## Enforcement

Maintainers may edit or remove content, close discussions, block an
account from project spaces, or reject contributions that violate this
code. Serious or repeated violations may receive a permanent ban.

Report conduct problems through a private GitHub message to the
repository owner. Do not include credentials or exploit details in a
conduct report.

## Scope

This code applies in repository issues, pull requests, discussions, and
other project spaces. It also applies when a participant represents the
project in public.
